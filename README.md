# Car Gallery Management System

A C# Windows Forms application developed to simplify car gallery operations through vehicle, customer and appointment management.

---

## Project Overview

This project was developed to digitalize vehicle gallery operations by providing:

- Vehicle inventory management
- Customer management
- Appointment tracking
- Sales representative operations
- Role-based system access

The system aims to improve operational efficiency and organize business processes in car gallery management.

---

## User Roles

The application includes different user roles with separate functionalities:

### Customer
- Access gallery services
- View vehicle-related information

### Sales Representative
- Manage appointments
- Track customer interactions

### Manager
- Add, update and delete vehicle records
- Manage sales representatives
- Monitor gallery operations

---

## Features

- Vehicle listing system
- Add / Update / Delete vehicle records
- Appointment management
- SQL Server database integration
- Role-based interface
- Desktop-based management system

---

## Technologies Used

- C#
- Windows Forms
- SQL Server
- .NET Framework

---

## Database

The application uses SQL Server to store:

- Vehicle information
- Customer data
- Appointment records
- Sales representative information
